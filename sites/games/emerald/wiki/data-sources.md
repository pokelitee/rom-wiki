# Data sources

## Primary ROM

- Pokémon Emerald (USA, Europe): header code `BPEE`, ROM version 0, SHA-256
  `a9dec84dfe7f62ab2220bafaef7479da0929d066ece16a6885f6226db19085af`.

## Publication model

Pokémon Emerald is published as a single-game retail reference.

## Coverage and provenance

This site derives Pokémon base data, moves, items, trainers, abilities,
wild encounters, locations, and the type chart directly from the ROM.
Location coverage is a real but bounded slice: 446 map headers verified
against real ROM data across five segments (every town/city exterior and
interior, the postgame legendary-encounter locations, New Mauville, and a
handful of routes), not an exhaustive scan of every map in the game.
PokéDB supplies reference identity, sprites, and Pokédex text; the wiki
always distinguishes ROM-derived facts from reference content.
