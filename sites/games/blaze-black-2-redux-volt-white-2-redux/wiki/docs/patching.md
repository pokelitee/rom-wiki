# Patching

Use a legally obtained clean USA/Europe copy of Pokémon Black Version 2 or
Pokémon White Version 2 with the matching Complete patch from the Redux
distribution. Do not apply Redux over another ROM hack or an already modified
base image.

The creator-maintained [patching guide](https://smilingzero.github.io/BlazeBlack2ReduxWiki/patchingGuide/)
describes the supported base images, patch variants, and optional patches. After
patching, `romwiki inspect --game blaze-black-2-redux` or
`romwiki inspect --game volt-white-2-redux` can verify whether the result is one
of the exact releases documented here.
