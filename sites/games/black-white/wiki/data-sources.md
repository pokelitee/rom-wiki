# Data sources

The primary sources are the exact USA/Europe NDSi-Enhanced releases of Pokémon
Black (header code IRBO, ROM version 0) and Pokémon White (header code IRAO,
ROM version 0). This is this project's first Generation V release and covers
Pokémon species data, Abilities, Items, Moves, Wild Encounters, Trainers, and
Locations.

Black and White are published as one wiki rather than two. Shared records are
shown once, while differing encounter tables, trades, and other same-key
records are rendered with explicit Black and White sections.

The sections below describe the shared Generation V Black/White engine record
formats and decoding techniques.
