This wiki covers the retail Pokémon FireRed and LeafGreen releases. Coverage is
currently limited to Pokémon base data and the type chart; other sections
(abilities, items, moves, wild encounters, trainers, locations) are not yet
implemented for this Generation III/Game Boy Advance engine. ROM provenance
and PokéDB reference content are kept distinct.

Pokémon FireRed and LeafGreen are published as one paired retail reference.
The two games are merged by stable record identity: shared records appear
once, while version-specific records state which game provides them.
