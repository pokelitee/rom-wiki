# Data sources

## Primary ROMs

- Pokémon FireRed (USA): header code `BPRE`, ROM version 0, SHA-256
  `3d0c79f1627022e18765766f6cb5ea067f6b5bf7dca115552189ad65a5c3a8ac`.
- Pokémon LeafGreen (USA): header code `BPGE`, ROM version 0, SHA-256
  `78d310d557ceebc593bd393acc52d1b19a8f023fec40bc200e6063880d8531fc`.

## Publication model

FireRed and LeafGreen are published as one paired retail reference. Both
ROMs are parsed independently and merged by stable record identity.

## Coverage and provenance

This site derives Pokémon base data and the type chart directly from the
ROMs. Other sections are not yet implemented for this engine. PokéDB
supplies reference identity, sprites, and Pokédex text; the wiki always
distinguishes ROM-derived facts from reference content.
